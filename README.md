# Battle City — консольная аркада на C# (.NET 10)

Интерактивный консольный аналог легендарной игры Battle City (NES/Dendy) без внешних графических зависимостей, с отрисовкой игрового поля в псевдографике, поддержкой цветной консоли, искусственным интеллектом вражеских танков и полным сохранением/загрузкой состояния в JSON.

## Особенности реализации

- **Модульная архитектура**: исходный код разделён на логические модули между членами бригады (`Entities.cs`, `GameEngine.cs`, `Storage.cs`, `ConsoleUi.cs`, `Program.cs`).
- **Игровое поле 10×10**: окружено рамкой, содержит танк игрока `[▲]`, вражеские танки `<▼>`, кирпичные стены `▓▓▓▓`, неразрушимые бетонные блоки `████`, штаб `⚑` и снаряды `●`.
- **Управление в реальном времени**: непрерывный игровой цикл (Game Loop) с неблокирующим считыванием нажатий клавиш (`Console.KeyAvailable`) и защитой от автоповтора при удержании клавиш (ровно один шаг танка за такт).
- **Снаряды и баллистика**: снаряды летят в направлении выстрела, разрушают кирпичные стены, наносят урон танкам и штабу, поглощаются неразрушимым бетоном. Корректно реализована стрельба в упор.
- **Искусственный интеллект врагов**: противники патрулируют карту, обходят препятствия, ориентируются на штаб игрока и производят выстрелы с вероятностью 25%.
- **Сериализация и сохранение**: полное сохранение и восстановление состояния игрового мира в JSON (`save.json`). При перезапуске предлагается загрузить сохранённую игру с обработкой повреждённых файлов.
- **Модульное тестирование**: 10 модульных тестов на xUnit, покрывающих игровую механику, физику снарядов, стрельбу в упор, здоровье объектов и сохранение/загрузку.

## Управление

| Клавиша | Действие |
|---|---|
| `W`, `A`, `S`, `D` или `Стрелки` | Поворот и движение танка |
| `Пробел` или `F` | Выстрел снарядом |
| `F5` | Быстрое сохранение игры в `save.json` |
| `R` | Перезапуск (новая игра) |
| `Q` или `Esc` | Выход из игры с автоматическим сохранением |

## Варианты запуска

### 1. Двойной клик по `run.bat` (Рекомендуется)
Запустите файл `run.bat` в папке проекта — игра автоматически откроется в отдельном окне терминала размером 76×28 колонок с кодировкой UTF-8.

### 2. Запуск из Visual Studio Code
В проекте настроен `.vscode/launch.json`:
* Нажмите клавишу **`F5`** (или перейдите в меню *Выполнить -> Запустить отладку*) — игра автоматически запустится **в отдельном системном окне терминала** (`externalTerminal`).

### 3. Запуск через консоль / PowerShell
```powershell
dotnet run
```

## Запуск модульных тестов

dotnet test tests/BattleCity.Tests.csproj
