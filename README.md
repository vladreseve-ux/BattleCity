# Battle City — консольная аркада на C# (.NET 10)

Интерактивный консольный аналог легендарной игры Battle City (NES/Dendy) без внешних графических зависимостей, с отрисовкой игрового поля в псевдографике, поддержкой цветной консоли, искусственным интеллектом вражеских танков и полным сохранением/загрузкой состояния в JSON.

## Особенности реализации

- **Игровое поле 10×10**: окружено границей, содержит танк игрока, вражеские танки, разрушаемые кирпичные стены, неразрушимые бетонные колонны, штаб (базу) игрока и снаряды.
- **Управление в реальном времени**: непрерывный игровой цикл (Game Loop) с неблокирующим считыванием нажатий клавиш (`Console.KeyAvailable`).
- **Снаряды и баллистика**: снаряды летят в направлении выстрела, разрушают кирпичные стены, наносят урон танкам и штабу, рикошетят от неразрушимого бетона.
- **Искусственный интеллект врагов**: противники патрулируют карту, обходят препятствия, двигаются в сторону штаба/игрока и ведут прицельный огонь.
- **Сериализация и сохранение**: полное сохранение и восстановление состояния игрового мира в JSON (`save.json`). При перезапуске предлагается загрузить сохранённую игру.
- **Модульное тестирование**: 8 модульных тестов на xUnit, покрывающих игровую механику, физику снарядов, здоровье объектов и сохранение/загрузку.

## Управление

| Клавиша | Действие |
|---|---|
| `W`, `A`, `S`, `D` или `Стрелки` | Поворот и движение танка |
| `Пробел` или `F` | Выстрел снарядом |
| `F5` | Быстрое сохранение игры в `save.json` |
| `R` | Перезапуск (новая игра) |
| `Q` или `Esc` | Выход из игры с автоматическим сохранением |

## Запуск игры

```powershell
dotnet run
```

## Запуск модульных тестов

```powershell
dotnet test tests/BattleCity.Tests.csproj
```
